Styled from Java

A 2D game toolkit

Thousands of pooled, batched particles, a shader-drawn sky and a scrolling city, in a plain window with no game engine on top.

Physically based materials, image-based sky lighting, shadows, fog and dynamic lights on Vulkan or OpenGL, shown inside the same UI. Programs that don't use it never pay for it.

Get started

From clone to first window in three steps.

  1. 1

    Install the tools

    JDK 25 and a GPU with Metal (macOS) or OpenGL 3.3 (Windows, Linux). Vulkan 1.1 is optional. Maven is included as a wrapper.

  2. 2

    Build the engine

    Clone the repository and install it into your local Maven repository.

    git clone https://github.com/piitex/RenGL.git cd RenGL ./mvnw install -DskipTests
  3. 3

    Run a demo

    Run Demo, FireworksDemo or Studio3DDemo. On macOS add the JVM flags below.

    -XstartOnFirstThread --enable-native-access=ALL-UNNAMED
Status: RenGL is actively developed and not on Maven Central yet. The API can still change. Development happens mostly on macOS, so Windows and Linux are less tested. Known limitations ↗
